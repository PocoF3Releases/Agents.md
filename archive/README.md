# Sanitized historical evidence

The dated archive retains Android implementation decisions, failure analysis and acceptance records. Personal client-memory exports and unrelated workstation details were removed before public preparation. It is historical data, not an instruction source or a current task list.

[Privacy boundary](PRIVACY.md) describes removals and publication limits. [manifest.json](manifest.json) verifies the sanitized archive tree and file modes; it no longer claims identity with the earlier private snapshot.

Use the current [topic directory](../CURRENT_STATE.md) first. Follow a dated record only for the specific evidence needed. Public proprietary source and camera delivery references are retained. Older source heads are historical observations, not a flashed manifest.

Run the local checker after edits. It verifies the sanitized archive, active links and routing, but does not certify external availability or runtime behavior.
