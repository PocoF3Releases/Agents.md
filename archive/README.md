# Archive skeleton

Outdated dated logs were consolidated into [final investigations](../memory/final-investigations.md)
and the owning [memory topics](../CURRENT_STATE.md), then removed at the
maintainer's request. Earlier Git revisions remain recoverable; the active
checkout contains no previous dated snapshot.

`records/` is empty except for .gitkeep. Add future sanitized decisive records
only when needed; update archive/manifest.json and the INDEX cold-archive hash
for any retained snapshot. Routine facts belong in their memory/state owner.
The local checker verifies the retained skeleton and active links.
[Public boundary](PRIVACY.md) applies to every new record.
