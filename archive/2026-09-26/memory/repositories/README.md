## Historical contribution ledgers

Individual ledger Markdown files in this directory preserve earlier attribution audits. They are not a current membership list, live commit count or checkout instruction. No contribution recount was performed by this source-map refresh. Private/unlisted repositories may require separate access; do not infer deletion from public-list absence. Consult these ledgers only for an explicitly requested history/attribution task.

For new work, resolve only the relevant remote head. An unchanged head needs no history scan. A rewritten head requires a semantic comparison, not replay of removed commits. See [remote workflow](../../REMOTE_WORKFLOW.md).
