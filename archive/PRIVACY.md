# Public repository boundary

Keep secrets, device identifiers, raw client-memory exports, signing material and
unrelated personal records out of this workhub. Public source identity and useful
sanitized Android findings belong in maintained topics. Reading/writing these
files does not synchronize hidden account memory.

Old logs were consolidated and removed October 9. Git retains older versions;
file removal or force-push cannot erase independent clones, forks or caches.
Pattern checks detect common sensitive formats, not every possible secret.
