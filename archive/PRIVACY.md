# Public repository boundary

Raw client-memory exports, unrelated personal workstation notes and private signing-repository inventories were removed for public preparation. Their contents are not required to use the maintained Android topics. Public source references, including proprietary-code repositories, are intentionally retained.

The dated archive is sanitized historical evidence, not a byte-for-byte copy of the original private knowledge store. The manifest verifies only the sanitized tree. Earlier knowledge-repository commits are not part of the new public branch history.

No repository visibility change is performed by this cleanup. A force-push replaces branch history but cannot erase independent clones, forks or hosting-provider caches. No credential values were found by the performed pattern scan; that scan is not a guarantee that every possible secret format is detectable.
